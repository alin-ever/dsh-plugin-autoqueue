# 周报生成

请帮我生成本周的工作周报：

1. 查看本周的代码提交记录（git log --since="last monday"）
2. 查看本周完成的任务或关闭的 issue/PR
3. 总结本周主要产出和里程碑
4. 记录遇到的风险或阻塞
5. 列出下周关键计划

## 输出格式

```
# 周报 — 第X周（日期范围）

## 本周完成
- 主要产出 1
- 主要产出 2

## 进行中
- 事项 1（进度: xx%）

## 风险/阻塞
- 风险 1（应对措施: xxx）

## 下周计划
- 关键事项 1
- 关键事项 2
```

保持简洁，每条不超过两行描述。
