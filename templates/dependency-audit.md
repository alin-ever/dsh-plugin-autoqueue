# 依赖安全扫描

检查项目依赖中的已知安全漏洞：

1. 运行适用的安全扫描命令（npm audit / yarn audit / pip-audit 等）
2. 分析高危漏洞的影响范围和利用条件
3. 评估升级依赖的兼容性风险
4. 给出可操作的修复建议（按优先级排序）

## 输出格式

```
## 扫描摘要
- 扫描工具: xxx
- 高危: x 个
- 中危: x 个
- 低危: x 个

## 高危漏洞详情
1. **package@version** — CVE-xxx
   - 影响: xxx
   - 修复: 升级到 xxx

## 修复建议（按优先级）
1. ...
```

## 约束

- 只关注有直接修复方案的漏洞
- 对于需要大版本升级的依赖，单独评估兼容性风险
- 不要在无人值守任务中自动执行升级操作
