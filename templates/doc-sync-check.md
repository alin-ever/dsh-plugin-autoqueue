# 文档一致性检查

检查项目文档是否与当前代码实现保持同步：

1. 对比 README 中描述的功能与实际代码
2. 检查 API 文档与路由/handlers 是否一致
3. 检查配置说明与默认值是否匹配
4. 检查环境要求（Node/Python 版本等）是否与实际依赖一致

## 输出格式

```
## 文档检查报告

### 一致项
- xxx

### 不一致项
1. **文件**: xxx
   - 文档说: xxx
   - 实际是: xxx
   - 建议: xxx

### 缺失文档
- xxx 功能缺少使用说明
```

## 约束

- 只检查项目自有文档，不检查第三方依赖文档
- 对于疑似不一致的项标注置信度（高/中/低）
- 不修改文档，只输出报告
